📥 Installation

1. Clone the repository

bash
git clone https://github.com/Suushy/PYTHON_BOT-DISCORD_CODE.git


2. Navigate to the project folder

bash
cd PYTHON_BOT-DISCORD_CODE


3. Install dependencies

bash

bash
python main.py
